description: Bluff is a real-time online multiplayer card game inspired by the classic "Cheat" / "I Doubt It" mechanics. Players can create or join game rooms and compete by strategically playing cards and calling bluffs. The game uses WebSockets for real-time synchronization, FastAPI for the backend game engine, and React + TypeScript for a responsive frontend UI. Deployed using Vercel (frontend) and Render (backend).
